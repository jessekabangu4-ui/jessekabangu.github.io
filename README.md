# Portfolio GitHub Pages

Ce dossier est prêt pour être publié sur GitHub Pages.

## Étapes

1. Créez un dépôt GitHub.
2. Uploadez le contenu de ce dossier à la racine du dépôt.
3. Allez dans Settings > Pages.
4. Choisissez :
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Enregistrez.

Votre site sera publié sur :
https://<votre-pseudo>.github.io/<nom-du-repo>/

Le CV sera accessible ici :
https://<votre-pseudo>.github.io/<nom-du-repo>/Jesse_up_cv.pdf

## Important

- Le fichier `Jesse_up_cv.pdf` doit rester dans le même dossier que `index.html`.
- Le fichier `.nojekyll` est présent pour éviter les traitements Jekyll sur GitHub Pages.
